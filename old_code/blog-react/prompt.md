../blog-vue-minimax 是一个基于 Vue 开发的轻量级个人博客项目，主页仅承担导航职责，作为所有子页面的统一入口。  
博客由多个独立页面组成，主要用于展示各类小游戏项目；点击项目卡片即可进入对应的子页，并支持 PWA 安装。  
游戏的具体业务逻辑托管在外部仓库中，当前子页仅放置空壳或简易占位组件，但结构完整，后续可零侵入地接入真实内容。

原始项目的技术要求如下：
1. 使用bun+vite+vue3(composition api)+typescript+pinia+vue-router开发
2. 需要部署到github pages
3. 尽量少使用Emits用于组件之间的通信，而是使用Pinia进行状态管理
4. 使用响应式页面开发，移动端优先，兼顾桌面端
5. 项目要符合vue开发的现代最佳实践

查看且不要更改原来项目的文件夹。根据原项目，使用react在目前的文件夹下重写这个项目。
要求：
1. 使用bun+vite+react+typescript+zustand+react-router+react-compiler开发
2. 使用符合react开发的现代最佳实践的官方模板创建项目
3. 需要部署到github pages
4. 使用响应式页面开发，移动端优先，兼顾桌面端
5. 项目要符合react开发的现代最佳实践。需要可以作为react初学者学习的典范。这是优先要求。为符合react开发的现代最佳实践，允许对项目结构进行一些必要的修改。
