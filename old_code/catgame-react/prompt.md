../catgame 是一个使用bun+vite+vue3(composition api)+typescript+pinia进行开发的给猫玩的抓鱼小游戏项目，使用网页和pwa两种方式部署在桌面端和移动端，移动端主要适配iPhone15及以上机型

查看且不要更改原来项目的文件夹。根据原项目，使用react在目前的文件夹下重写这个项目。
要求：
1. 使用bun+vite+react+typescript+zustand+react-router+react-compiler+PWA开发
2. react compiler目前已经稳定，将自动进行记忆化，故不需要再使用useMemo、useCallback和React.memo
3. 使用符合react开发的现代最佳实践的官方模板创建项目
4. 这个项目将作为需要部署到github pages的react个人博客的一个子页面
5. 使用响应式页面开发，移动端优先，兼顾桌面端
6. 项目要符合react开发的现代最佳实践。需要可以作为react初学者学习的典范。这是优先要求。为符合react开发的现代最佳实践，允许对项目结构进行一些必要的修改。
